# SatUsPhere

Bitcoin education platform with an interactive tools hub covering core concepts for self-custody and long-term investing.

## What it does

- Full landing page with course enrollment (Teachable integration)
- Nine custom-built Bitcoin education tools (see `/tools`)
- SEO-optimized content pages on Bitcoin fundamentals
- Kit email capture for lead generation

## Tools included

- **DCA Calculator** — historical returns + goal planner mode
- **Halving Clock** — live countdown to the next Bitcoin halving
- **Self-Custody Readiness Quiz** — personalized wallet type recommendation
- **Wallet Selector** — filtered comparison of 18 hardware and software wallets
- **Satoshi Converter** — real-time BTC/USD/sats conversion
- **Stack the Sats** — dual-direction savings goal calculator
- **Learning Roadmap** — 9-stage curriculum with embedded YouTube lessons

## Tech stack

- **Frontend:** HTML, CSS, JavaScript (vanilla), React (select components)
- **Deployment:** Vercel (auto-deploys from GitHub)
- **Email:** Kit (ConvertKit)
- **SEO:** Structured data (JSON-LD), Open Graph, sitemap, robots.txt
